# auto-research

文献与开源实现调研 skill。

| Skill | 用途 | 配套资源 |
|---|---|---|
| [academic-paper-review](academic-paper-review/SKILL.md) | 单篇论文结构化精读、方法评估与贡献分析 | 方法推演与评审输出要求包含在 SKILL.md 中 |
| [systematic-literature-review](systematic-literature-review/SKILL.md) | 多论文系统综述、交叉比较与书目整理 | arXiv 检索脚本、APA / IEEE / BibTeX 模板、评测样例 |
| [github-deep-research](github-deep-research/SKILL.md) | GitHub 仓库多轮调研与实现分析 | GitHub API 脚本、报告模板 |

每个 skill 目录可独立取用；引用的脚本、模板和评测文件随目录保留。

各 `SKILL.md` 末尾记录原始来源与本地修改，目录内保留对应上游许可文本。当前归档保留既有方法正文。`systematic-literature-review` 文档仍有 Kimi Code 的 `Agent` / `AgentSwarm` 调用约定与 `~/.agents/skills/` 安装路径；评测样例含历史输出环境约定。迁移到其他运行环境时，请按对应工具和路径调整。
